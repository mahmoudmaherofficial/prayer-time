# Prayer Time

A simple Arabic prayer times web app that displays daily prayer timings based on the selected country and city.

## Features

- Arabic RTL interface
- Country and city selection
- Daily prayer times display
- Highlights the next upcoming prayer
- Shows Gregorian and Hijri dates

## Tech Stack

- HTML
- CSS
- JavaScript
- Bootstrap via CDN
- Axios via CDN

## Data Sources

- [Aladhan API](https://aladhan.com/prayer-times-api) for prayer times
- [CountriesNow API](https://countriesnow.space/) for countries and locations

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.

You can also serve the project with any simple local server if you prefer.

## Notes

- Internet access is required because the app uses CDN assets and external APIs.
- The default selection is Egypt / Monufia.
